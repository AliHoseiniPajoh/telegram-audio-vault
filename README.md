# 🎧 Telegram Audio Vault (صندوقچه صوتی شخصی)

یک **Telegram Mini App (TMA)** کاملاً اختصاصی و خصوصی برای ذخیره، مدیریت و استریم فایل‌های صوتی، پادکست‌ها و پیام‌های صوتی شخصی کاربر در محیط تلگرام.

---

## ✨ ویژگی‌های کلیدی

- **🔒 کاملاً خصوصی و ایزوله:** بدون تب اکسپلور، بدون پیشنهادات عمومی، بدون فروشگاه و بدون درگاه پرداخت.
- **🛡 امنیت سخت‌گیرانه (Whitelist):** اعتبارسنجی داده‌های `initData` با الگوریتم HMAC-SHA256 و مسدودسازی کامل هرگونه دسترسی به غیر از `ALLOWED_USER_ID`.
- **🎨 رابط کاربری مینیمال با تم تلگرام:** همگام‌سازی ۱۰۰٪ با پالت رنگی لایت و دارک تلگرام با متغیرهای `--tg-theme-*`.
- **⚡ بارگذاری لحظه‌ای (Zero-Asset Latency):** پیاده‌سازی تمام آیکون‌ها و کنترل‌ها به صورت وکتور خالص درون‌کدی (Inline SVG) بدون وابستگی به تصاویر یا فونت‌های خارجی.
- **🎵 موزیک پلیر شناور و تمام‌صفحه:**
  - نوار شناور پایینی شیشه‌ای (Mini Player) با نمایش مشخصات و نوار پیشرفت باریک.
  - شیت تمام‌صفحه بازشونده (Expanded Sheet) با انیمیشن روان، اسکرابر دقیق، حالت تکرار (Repeat 1 / All)، پخش تصادفی (Shuffle)، تغییر سرعت (0.75x تا 2x) و ادغام با دکمه بازگشت بومی تلگرام (`Telegram.WebApp.BackButton`).
  - یکپارچگی کامل با **MediaSession API** مرورگر جهت کنترل صدا در صفحه قفل (Lock Screen) و بخش نوتیفیکیشن‌های موبایل.
- **📁 مدیریت فایل و پلی‌لیست:** دریافت خودکار فایل‌ها و وویس‌ها از چت ربات، امکان ساخت پلی‌لیست، جستجوی بلادرنگ و حذف فایل‌ها.
- **📡 استریم امن (Audio Proxy):** استریم مستقیم و امن از سرورهای تلگرام بدون فاش شدن توکن ربات برای کلاینت.

## 🚀 راهنمای راه‌اندازی و اجرا

### ۱. نصب وابستگی‌ها
```bash
cd telegram-audio-vault
npm install
```

### ۲. دریافت توکن و آیدی تلگرام
1. در تلگرام به ربات **[@BotFather](https://t.me/BotFather)** پیام دهید و یک ربات جدید با `/newbot` بسازید تا توکن (`BOT_TOKEN`) را دریافت کنید.
2. آیدی عددی تلگرام خود را از ربات **[@userinfobot](https://t.me/userinfobot)** بگیرید (`ALLOWED_USER_ID`).

### ۳. تنظیم فایل `.env`
فایل `.env.example` را کپی کرده و به نام `.env` ذخیره کنید:
```env
BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz
ALLOWED_USER_ID=987654321
PORT=3000
WEBAPP_URL=https://your-domain-or-ngrok.app
NODE_ENV=development
```

### ۴. اجرای تست‌های خودکار
برای اطمینان از درستی امضای دیجیتال و عملیات ذخیره‌سازی:
```bash
npm test
```

### ۵. اجرای سرور
```bash
npm start
```
یا در حالت توسعه:
```bash
npm run dev
```

### ۶. اتصال به تلگرام (برای تست محلی)
از آنجا که تلگرام برای Mini App نیاز به آدرس **HTTPS** دارد، می‌توانید از ابزارهایی مانند `cloudflared` یا `ngrok` استفاده نمایید:
```bash
npx ngrok http 3000
```
سپس آدرس HTTPS دریافتی را در متغیر `WEBAPP_URL` در فایل `.env` و همچنین در دستور `/newapp` یا منوی ربات در `@BotFather` قرار دهید.

## 🔒 امنیت و حریم خصوصی

- **کلاینت‌های غیرمجاز:** هر درخواستی که امضای معتبر تلگرام نداشته باشد یا مقدار `user.id` آن با `ALLOWED_USER_ID` تطابق نداشته باشد بلافاصله با خطای `403 Forbidden` متوقف می‌شود.
- **ربات در چت:** اگر کاربری غیر از مالک پیامی ارسال کند، ربات پاسخی جز پیام مسدودیت نمی‌دهد و هیچ فایلی ذخیره نمی‌کند.
- **حفاظت از توکن ربات:** فایل‌های صوتی از طریق پروکسی سرور استریم می‌شوند و توکن ربات هرگز به سمت کلاینت فرستاده نمی‌شود.
